# materials/ — 社團素材

把改造網站要用的東西放這裡，AI 會從這裡讀。檔名用英文或數字比較不會出問題。

| 放什麼 | 建議檔名 | 說明 |
|---|---|---|
| 標誌 | `logo.svg`（或 `logo.png`） | SVG 最好；PNG 至少 512×512、透明背景 |
| 小圖示 | `icon.svg` | 瀏覽器分頁上的小圖；沒有就用標誌 |
| 配色參考 | `colors.png` 或寫在 `club.md` | 社服、海報、IG 截圖都可以 |
| 現有表單 | `forms/` | 報名表、請假表、出席表的截圖或 Excel |
| 範例資料 | `samples/` | **只放假資料**：欄位要跟真的一樣，內容用虛構的 |
| 參考畫面 | `screens/` | 喜歡的網站截圖、想要的畫面草圖 |

注意：

- **不要放真實的成員名單、電話、學號、Email。** 這個 repo 是公開的。真實資料等網站上線後，由管理員從網站匯入。
- **不要放任何密碼、金鑰、webhook 網址。** 見 `AGENTS.md` §5。
- 有版權的圖片（別人的照片、字型）確認可以用再放。
